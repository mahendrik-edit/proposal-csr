# Proposal CSR · SMP Negeri 14 Malang

Website proposal interaktif. Cara memakai di GitHub Pages:

1. Unggah seluruh isi folder ini ke repositori (index.html, folder assets, file .docx, .nojekyll).
2. Buka Settings > Pages, pilih Deploy from a branch, branch `main`, folder `/ (root)`.
3. Situs aktif di `https://<username>.github.io/<nama-repo>/`.

Yang masih perlu diisi di `index.html`: [tanggal], [nomor surat], dan [Nama Ketua Komite] (cari teks tersebut pada bagian surat permohonan).
